## 不重复扣分的边界

- 心跳和空增量被适配器丢弃，TTFT 记在首个非空内容上，不扣。
- 400 不重试，401 映射为 503 且不重试。SDK `max_retries=0`，实际次数未超过首次加 3 次。
- 成功前 JSON 校验能拒绝非法、空、截断内容。围栏剥离发生在校验前，成功正文不再是非法 JSON，不另扣。
- 缺模板、缺版本、缺变量返回明确 400，不扣。
- 本地超限返回的是 HTTP 429，不是 200 包错误，429 子项不扣。
- 流内错误事件被识别为失败，不按“错误事件当成功”扣；只对无成功终态 EOF 扣终止处理。
