## D. 扣分复现与固定源码位置

以下命令在归档按 replay.sh 布置的 `/tmp/sunny-grade/student` 目录执行，使用同一固定源码。每项仅扣对应评分子项，不因双协议/多输入重复扣分。

### D1. 截断结构化正文被当作成功：结构化输出 −2

- 触发：Chat 上游返回 `finish_reason=length`，正文为完整语法的 `{"answer":7}`，请求 response_format=json_object。
- 预期：结构化结果必须确认未截断，明确失败；不能仅因可解析而成功。
- 实际：HTTP 200，parsed={answer:7}，attempts=1。对照 Responses status=incomplete 明确失败；残缺正文也会失败，问题限于终态丢失。
- 复现：`.venv/bin/python -m pytest -c pyproject.toml ../teacher_tests.py -k truncated_valid_json -v`。
- 源码：固定提交 `gateway/providers.py:50–62`，完整响应未读取 finish_reason 即构造 Result；`gateway/services/structured.py:8–17` 只能校验正文，不知道终态。
- 证据：teacher-results.json 的 F04_truncated_valid_json/chat；teacher-pytest.log 对应 HTTP 200 断言失败。只扣失败处理子项2分，普通流式 length 不另扣。

### D2. 格式不支持的上游 400 被改为 502：统一错误与重试 −1

- 触发：Responses 结构化请求，受控上游以 HTTP 400 拒绝格式。
- 预期：统一错误正文，同时返回明确4xx、不重试。
- 实际：1次上游请求，HTTP 502 upstream_error；无重试部分正确，状态分类错误。
- 复现：`.venv/bin/python -m pytest -c pyproject.toml ../teacher_tests.py -k unsupported_format -v`。
- 源码：`gateway/core/errors.py:17–25` 对 APIStatusError 未传 status，落入 `:5` 默认502。
- 证据：teacher-results.json 的 F03_unsupported_format。只扣状态映射1分，不再次扣接口、结构化或脚本分。

### D3. Schema 悬空本地引用误归因为上游错误：统一错误与重试 −1

- 触发：Schema properties.answer.$ref=`#/$defs/missing`，但只定义 `$defs.value`；模型返回合法 {answer:7}。
- 预期：明确的 Schema 入参错误，宜在请求模型前拒绝；正常 `#/$defs/value` 应通过。
- 实际：正常引用200；悬空引用先请求模型，再返回502 upstream_error / Provider returned an invalid response。不是500，但仍把本地 Schema 配置错误错误归因于供应商。
- 复现：`.venv/bin/python -m pytest -c pyproject.toml ../teacher_tests.py -k schema_local_ref -v`。
- 源码：`gateway/models.py:26–44` 仅校验 Schema 语法与本地前缀，未解析引用；`gateway/services/structured.py:15–18` 未分类引用解析异常，落入 `gateway/core/errors.py:26` 通用上游错误。
- 证据：teacher-results.json 的 B02_B03 正反对照及失败 trace。此为本地引用校验根因，与 D2 的上游状态映射不同；只扣错误处理1分，不再扣结构化和失败记录。

### D4. 正向抖动突破指数等待上界：统一错误与重试 −1

- 触发：base=0.25，受控500两次再成功，固定随机乘子1.25。
- 预期：按统一标准 F08/5.4，第1、2次等待分别≤0.25、0.5秒；允许范围内抖动。
- 实际：实际 SDK 请求3次成功，但等待记录为0.3125、0.625秒。随机乘子1的对照为0.25、0.5秒；指数和次数本身正确。
- 复现：`.venv/bin/python -m pytest -c pyproject.toml ../teacher_tests.py -k backoff_actual_calls -v`。
- 源码：`gateway/core/retry.py:4–6` 使用 uniform(1,1.25)，`gateway/services/gateway.py:92–93` 使用该等待。README 如实声明了额外25%抖动，但仍超统一验收的指数上界；因此仅在退避子项4分中扣1分，不扣次数或文档分。
- 证据：teacher-results.json 的 F08/factor=1、1.25；teacher-pytest.log。没有以偶发真实时延判分。
