**1. 作业等级：不及格（50分）**

**2. 作业优点**

**3. 作业不足**

- 两个真实适配器实际均为 Chat Completions，未满足双协议要求；未知模型会静默回退 Mock。
- 未实现结构化输出和提示词版本管理。response_format 被忽略，非法、空、截断 JSON 仍标记完成；模板版本与变量没有处理入口。

**4. 改进方案**

- 增加统一 JSON 约束与成功前解析校验，拒绝非法、空和截断结果；补齐模板存储、变量替换、v1/v2 引用及缺项处理。
- 按运行记录总延迟、首个有效内容延迟，消费完整用量事件；验证正文、心跳、独立 usage 帧和失败调用的账本。
- 为输出前的临时失败实现有上限的指数退避，继续保持输出后不重试；增加可配置的模型独立配额，验证 HTTP 429、隔离及窗口恢复。
- 扩充验收脚本，以预期输出和错误行为断言六项能力；保留故障注入，修复后重新运行全套教师验收。
