# 第一周作业反馈

学员：G20245506050001（Geek_ae23cc）

**1. 作业等级：优秀（98分）**

**2. 作业优点**

- 同一入口可按 model 切换 Responses 与 Anthropic Messages；两个模型的官方接口普通调用、流式调用和 JSON 输出均已实测成功。
- 流式支持真实增量下发；上游缺失终止事件时能返回错误，且已输出内容后不会重新请求导致重复生成。
- 提示词具有持久化、变量替换和不可变版本；验证覆盖旧版本引用、缺失变量以及版本不存在等场景。
- 单元测试40项、完整验证92项通过；模型独立限流、指数退避、失败记录及流式首Token延迟均有可复现证据。

**3. 作业不足**

- 上游因请求参数返回400时，网关虽然保留统一错误码且没有重试，但对外返回502，调用方不易区分参数问题与服务故障。
- 已支持JSON Schema，但引用不存在的本地定义时会先调用上游，随后返回500；当前校验未将这类无效请求转成明确的输入错误。

**4. 改进方案**

- 保持统一错误信封，并将上游参数类错误映射为明确的4xx；补充400与503对照用例，确认只有可恢复错误进入重试。
- 在请求阶段检查Schema本地引用，或捕获引用解析异常并返回明确4xx；同时验证有效引用仍正常，错误引用不触发内部500且尽量不消耗上游调用。
