**3. 作业不足**

- 同一入口不能仅切换 model 跨协议调用；协议由接口路径决定，尚未完成要求的统一模型适配。
- 官方 Responses 流含 reasoning_text 内容事件时被判为不支持，尚不能完成该模型的真实流式调用。
- 限流桶仅按租户计数，模型 A 耗尽后模型 B 同样被拒绝，未满足按模型独立限流。
- 退避在指数值上额外加正抖动，实测等待超过评分标准规定的指数上界。
- README 沿用本机绝对路径与未交付的包层级，直接克隆无法运行所示模块命令，需要教师外部目录映射。

**4. 改进方案**

- 在统一入口根据 model 选择上游协议，并验证只替换模型名就能分别完成两种协议调用。
- 补齐 Responses 推理内容事件兼容；用附件官方流回放与真实模型复验，确认有正文和成功终态。
- 以模型或“租户＋模型”分桶；验证 A 超限返回 429、B 正常，并在补充配额后恢复 A。
- 在指数上界内采样抖动，记录等待与实际请求数，验证成功、持续失败及鉴权错误三类场景。
- 改为克隆后可执行的相对路径启动说明；补齐统一跨协议、真实推理流和模型隔离验收，再在干净环境复跑。
