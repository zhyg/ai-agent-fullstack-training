# 第一周作业反馈

学员：G20210735010342（魂痴冬冬）

**1. 作业等级：优秀（95分）**

**2. 作业优点**

- Responses 与 Messages 适配器实现了统一路由；两个模型的官方真实普通调用、JSON 输出和流式输出均已验证，Flash 使用外部配置映射至官方模型名。
- 双协议门控测试确认内容在上游结束前到达；显式错误和传输断流均不会重新生成已输出内容。
- 模板 v1/v2 可分别引用，缺模板、版本和变量有明确错误；按模型限流、隔离和配额恢复均通过。
- 学生离线测试 8 项通过；教师验证了指数退避、实际重试上限、分类用量和正文首 Token 延迟。

**3. 作业不足**

- 两种协议在输出部分文本后直接结束、没有成功终态时，仍返回正常结束并记录成功，调用方无法发现内容缺失。
- 上游已返回用量但正文未通过 JSON 校验时，失败记录中的输入、输出和总 Token 被记为 0。
- 未知模型虽正确返回 404，但该失败请求无法按请求 ID 查询到调用记录。

**4. 改进方案**

- 仅在收到协议成功终态后发送正常结束；补测输出文本后直接 EOF，确认下游收到错误、账本记失败且不重试。
- 在执行正文校验前保留已知用量；以非法 JSON 加明确用量复测，确认失败账本保留实际 Token 分类。
- 将未知模型等准备阶段失败纳入统一记录；用错误响应的请求 ID 查询，确认有对应失败账目。
